# Privacy Policy

X Keyboard Extras does not collect, store, sell, or transmit personal data.

The extension runs locally in Chrome on `x.com` and `twitter.com` pages. It adds keyboard shortcuts for expanding posts, opening referenced posts, invoking X's Grok action, and copying a screenshot of the visible part of the selected post.

The `clipboardWrite` permission is used only when the user presses `Shift+S` to copy a selected post screenshot to the clipboard. The extension does not read clipboard contents.

The extension does not use analytics, tracking, remote code, external services, or a backend server.
